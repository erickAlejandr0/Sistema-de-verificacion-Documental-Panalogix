# Historias de Usuario

Las historias de usuario describen las necesidades funcionales del sistema desde la perspectiva de cada actor.

Todas siguen el formato:

> **Como** *[rol]*, **quiero** *[funcionalidad]*, **para** *[beneficio]*.

---

# 8.1 Transportista

| ID | Historia de Usuario |
|----|---------------------|
| **HU-01** | Como **transportista**, quiero subir mis documentos desde mi celular, para completar mi verificación sin realizar trámites presenciales. |
| **HU-02** | Como **transportista**, quiero recibir una notificación cuando mi documento sea verificado, para saber si puedo operar dentro de la plataforma. |
| **HU-03** | Como **transportista**, quiero recibir alertas antes del vencimiento de mis documentos, para renovarlos oportunamente y no perder oportunidades de trabajo. |
| **HU-04** | Como **transportista**, quiero visualizar un sello de verificación en mi perfil, para generar confianza en las empresas y acceder a más oportunidades de flete. |

---

# 8.2 Equipo Panalogix

| ID | Historia de Usuario |
|----|---------------------|
| **HU-05** | Como **miembro del equipo Panalogix**, quiero revisar los casos clasificados como revisión manual desde un panel centralizado, para resolverlos con toda la información disponible. |
| **HU-06** | Como **miembro del equipo Panalogix**, quiero que las correcciones realizadas alimenten el sistema, para mejorar continuamente la precisión del proceso de verificación. |
| **HU-07** | Como **miembro del equipo Panalogix**, quiero consultar métricas de precisión, volumen y desempeño, para evaluar el comportamiento del sistema. |
| **HU-08** | Como **miembro del equipo Panalogix**, quiero visualizar el costo por documento procesado y el gasto acumulado, para controlar el presupuesto operativo. |

---

# 8.3 Empresa (a través de Panalogix)

| ID | Historia de Usuario |
|----|---------------------|
| **HU-09** | Como **empresa**, quiero contratar transportistas cuya documentación ya haya sido verificada, para reducir el riesgo legal y operativo asociado al servicio de transporte. |
| **HU-10** | Como **empresa**, quiero consultar el estado de verificación de un transportista antes de asignarle un flete, para tomar decisiones fundamentadas. |
